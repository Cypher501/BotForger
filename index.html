02 / Create your bot account

Follow these steps in Telegram to get a bot token.

1
Open @BotFather

In Telegram, search for @BotFather and open the verified bot.

2
Create your bot

Send /newbot, choose a display name, then a username ending in bot.

3
Copy the API token

BotFather will provide a token. Keep it private; it grants control of your bot.

1
Open Discord Developer Portal

Visit discord.com/developers/applications and sign in.

2
Create an application and bot

Choose New Application, give it a name, open the Bot section, then add a bot if prompted.

3
Reset and copy the bot token

In the Bot section, use Reset Token / View Token and copy it. Never share it.

4
Enable message content intent

Under Bot → Privileged Gateway Intents, enable Message Content Intent for this text-reply starter.

5
Invite your bot to a server

Use OAuth2 → URL Generator, select bot scope and permissions to view channels and send messages, then open the generated invite URL.

🔒
Keep your token secret. This page uses it only to create your local .env download. It is not sent to a server. Never commit .env to Git. If exposed, regenerate it in the platform's bot settings.
